# Portugal Administrative GIS Dataset

Port
[Portugal Freguesia Population Dataset](https://github.com/mdhasanuzzamanbp/portugal_administrative_gis/releases/tag/v2.0)

## Included datasets

1. Portugal Regional Administrative NUTS Boundary
- Administrative boundary reference: 2024
- Geographic level: NUTS 1, NUTS 2 and NUTS 3 
- Coordinate reference system: EPSG:3035

2. Portugal Local Administrative Boundary
- Administrative boundary reference: 2025
- Geographic level: Freguesia and Municipality
- Coordinate reference system: EPSG:3035 

The Shapefile package contains:
- .shp
- .shx
- .dbf
- .prj



## 2. Portugal Freguesia Population Dataset
- Population reference year: 2021
- Geographic level: Freguesia
- Coordinate reference system: EPSG:3035

The Shapefile package contains:
- .shp
- .shx
- .dbf
- .prj
